📋 Инструкция по использованию

Как работает система:

  1. Распечатайте эту страницу с QR-кодами
  2. Разместите QR-коды на столах в бургерной (можно ламинировать)
  3. Также нужна Hiro-метка - её можно скачать ниже или показать на экране
  4. Гость сканирует QR-код телефоном → открывается страница с бургером
  5. Разрешает доступ к камере
  6. Наводит на Hiro-метку → появляется 3D модель бургера!

Hiro-метка (AR Marker):

Эту метку нужно распечатать или показать на экране. Гость наводит камеру на неё, чтобы увидеть бургер.

Пример Hiro-метки. Рекомендуется использовать стандартную Hiro-метку из AR.js

Важно: Для работы AR необходимо:
  • Современный смартфон с камерой
  • Браузер Chrome, Safari или Firefox
  • Разрешение на использование камеры
  • Hiro-метка (можно найти в Google по запросу "Hiro marker AR.js")
