🍔 BURGRS - Маркеры для AR

Распечатайте маркеры и QR-коды для бургерной

📋 Как использовать AR маркеры

  1. Распечатайте эту страницу на обычном принтере (черно-белый подойдет)
  2. Разместите маркеры на столах - один маркер для каждого бургера
  3. Гость открывает сайт по QR-коду или по ссылке
  4. Наводит камеру на маркер - появляется 3D модель бургера!
  5. Каждый маркер уникален - показывает свой бургер
Важно: Маркеры должны быть напечатаны четко, без размытия. Размер маркера - минимум 5x5 см.

  2. QR-коды - для открытия сайта на телефоне гостя
