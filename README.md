# 🍔 BURGRS WebAR

Интерактивное WebAR приложение для бургерной. Гости сканируют QR-коды в меню и видят 3D модели бургеров в дополненной реальности!

## 📁 Файлы проекта

- `index.html` - Главная страница с выбором бургеров
- `ar-viewer.html` - AR просмотрщик (открывается при сканировании QR)
- `menu-print.html` - Страница для печати QR-меню

## 🚀 Как использовать

### 1. Локальное использование
Просто откройте `index.html` в браузере.

### 2. Для публикации
1. Загрузите все файлы на веб-хостинг (GitHub Pages, Netlify, Vercel и т.д.)
2. Сгенерируйте QR-коды для каждого бургера
3. URL для QR-кода: `https://ваш-сайт.com/ar-viewer.html?burger=НАЗВАНИЕ`

### 3. Названия бургеров для URL:
- `burger` - Classic Burger
- `big-burger` - Big Burger  
- `zinger` - Zinger Burger
- `hamburger` - Hamburger
- `hamburger2` - Hamburger 2
- `burger-low` - Burger Low

## 🎯 Механика работы

1. **QR-код на столе** → Гость сканирует камерой телефона
2. **Открывается AR страница** → Выбранный бургер загружается
3. **Разрешение камеры** → Необходимо для AR
4. **Hiro-метка** → Гость наводит на метку (распечатанную или на экране)
5. **3D бургер появляется!** → В дополненной реальности на столе

## 📱 Hiro-метка

Для работы AR необходима Hiro-метка. Её можно:
- Распечатать (поиск в Google: "Hiro marker AR.js")
- Показать на экране другого устройства
- Использовать стандартную метку из AR.js

## ⚙️ Технологии

- **A-Frame** - 3D фреймворк
- **AR.js** - Библиотека для WebAR
- **GLTF/GLB** - Формат 3D моделей

## 🎮 Управление в AR

- **Вращать** - Автоматическое вращение модели
- **Увеличить/Уменьшить** - Масштабирование 3D модели
- **Назад** - Возврат в меню

## 💡 Советы

1. Используйте хорошее освещение для лучшего распознавания
2. Держите телефон стабильно
3. Hiro-метка должна быть четко видна
4. Для лучшего опыта используйте современные смартфоны

## 🌐 Совместимость

- iOS Safari (iPhone 6s+)
- Android Chrome
- Android Firefox

## 📞 Поддержка

Если возникли проблемы:
1. Проверьте, что камера работает
2. Разрешите доступ к камере в браузере
3. Используйте Hiro-метку хорошего качества
4. Убедитесь в хорошем освещении
